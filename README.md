# WireframeStudio

A local, wireframe.cc-style website planning tool. **Double-click `index.html`** to open it — no server, no install, no account. Works in any modern browser (Chrome/Edge/Firefox).

## What you get

- **55 draggable elements** in a searchable palette across five categories — including text, headline, **block text with real editable lorem ipsum**, grey bars, lists (bulleted and numbered), text links, badges, sliders, solid/outline buttons, search box, contact form, images, video, QR, nav bar, hero + split hero, cards (tall, wide, row of 3), gallery, pricing table, stats row, FAQ list, testimonial, chat bubble, footer, browser frame, tabs, pagination, breadcrumb.
- **A Mobile category** for phone-first planning: nav bar with **hamburger menu**, the menu opened state (editable stacked links), bottom tab bar, mobile hero, app list rows, floating action button, and a phone frame to mock the whole device.
- **Drag from the palette onto the page anywhere**, or click a palette item then click where you want it (hold Shift to place several).
- **Double-click any text** to edit it inline — nav and breadcrumb labels stay visible after you click away.
- Selection toolbar with **fill presets, fade, font picker (Sans / Serif / Mono / Playful), text size**, layer order, duplicate, lock, delete — plus **image placeholder style** (X cross corner-to-corner / photo icon / plain fill).
- Multi-select (Shift-click, marquee drag), snapping with alignment guides, grid toggle, zoom (Ctrl+scroll or Ctrl +/-/0).
- Desktop / Tablet / Mobile page presets plus custom page size.
- **Undo/redo** (150 steps), keyboard shortcuts throughout (`?` opens the full help).
- **Autosave** to the browser; **Export JSON / Import** for portable copies; **Export PNG** for a clean image of the page.
- Starter templates: Blank, Landing page, Product page, Blog post, Contact page, **Mobile page** (390px phone layout pre-stocked with hamburger nav, hero, card, list rows, FAB, bottom tab bar).

## Files

| File | Purpose |
|---|---|
| `index.html` | Open this. Loads everything else. |

## Notes

- Autosave lives in your browser's localStorage for this folder — if you move the folder to another path or machine, use **Export JSON** to carry your work across (Import reopens it).
- Exported PNG renders at 2x resolution.
