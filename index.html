WireframeStudio

A fully local wireframe builder. Everything runs in this file — no server, no account.

Building

  • Drag an item from the left palette onto the page, anywhere you like.
  • Or click a palette item, then click on the page to place it. Esc cancels.
  • Double-click any text inside an element to edit it.
  • Drag elements to move them; drag the corner handles to resize.
  • Shift+click adds to the selection; drag empty canvas to marquee-select.
  • Alt+drag an element to duplicate it.

Shortcuts

  • Del delete   Ctrl+D duplicate   Ctrl+C/V copy/paste
  • Ctrl+Z / Ctrl+Y undo / redo
  • Arrow keys nudge, Shift+arrows ×10
  • [ / ] send back / bring front
  • Ctrl+scroll or Ctrl +/-/0 zoom
  • G grid   S snap   Esc deselect

Saving

  • Work autosaves to this browser (localStorage).
  • Export JSON keeps a portable copy; Import reopens it.
  • Export PNG downloads an image of the current page.
